# plan

Produce a short written plan before touching code.

1. Restate the goal in one sentence.
2. List the files you expect to read or change.
3. List the risks and unknowns.
4. Propose the smallest sequence of steps.
5. Ask the user to confirm before implementing.

Never start editing while the plan is unconfirmed.
