# dream

Turn scattered session notes into a durable, topic-organized index.

1. Read the notes and past work summaries.
2. Extract decisions, patterns, and gotchas worth keeping long-term.
3. Merge them into the memory index by topic, deduplicating.
4. Keep entries short, dated, and link back to their source sessions.
5. Never delete history; only add or refine.
