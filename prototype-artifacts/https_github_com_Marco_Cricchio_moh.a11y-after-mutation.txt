                    - /url: "#what-is-moh"
                - paragraph [ref=e541]: "moh is a coding agent that lives in your terminal: you describe what you want in plain language, and moh reads your code, edits files, runs commands, and gets the work done — showing you every step and asking permission before anything risky."
                - paragraph [ref=e542]: "Three things make it different:"
                - list [ref=e543]:
                  - listitem [ref=e544]:
                    - strong [ref=e545]: It works with the AI provider you choose.
                    - text: Anthropic, OpenAI, Google, GitHub Copilot, OpenRouter, Kimi, xAI — plus 16 pre-built hosted OpenAI-compatible endpoints (DeepSeek, Groq, Cerebras, Mistral, Moonshot, …) and local models too (Ollama, LM Studio), all through one configuration. If a provider goes down, moh falls back to the next one on your list. Your agent setup is never locked to a single vendor.
                  - listitem [ref=e546]:
                    - strong [ref=e547]: Your data stays yours.
                    - text: Sessions, memory, and notes live in a plain append-only log on your machine (
                    - code [ref=e548]: ~/.moh/
                    - text: ) — nothing is ever deleted, and you can resume, fork, or compact any session at any time.
                  - listitem [ref=e549]:
                    - strong [ref=e550]: It asks before it acts.
                    - text: A layered permission system gates every file write and every shell command; extensions can veto actions but can never grant more than you allowed.
                - generic [ref=e551]:
                  - heading "Highlights" [level=2] [ref=e552]
                  - 'link "Permalink: Highlights" [ref=e553] [cursor=pointer]':
                    - /url: "#highlights"
                - list [ref=e556]:
                  - listitem [ref=e557]:
                    - strong [ref=e558]: Terminal UI (TUI)
                    - text: — a fast, keyboard-driven interface with file mentions (
                    - code [ref=e559]: "@path"
                    - text: ), image previews, session picker, and guided provider onboarding. Or go headless with
                    - code [ref=e560]: moh run
                    - text: for scripts and CI — no prompts, fail-fast.
                  - listitem [ref=e561]:
                    - strong [ref=e562]: Workflow mode
                    - text: — an optional first-party port of the Matt Pocock agent workflow (wayfinder, grilling, to-spec, to-tickets, tdd, code-review, …) plus declarative GitHub repo management (
                    - link "gh-manager" [ref=e563] [cursor=pointer]:
                      - /url: https://github.com/ddlaws0n/gh-manager
                    - text: ", by David Lawson). One command to turn it on:"
                    - code [ref=e564]: /workflow on
                    - text: .
                  - listitem [ref=e565]:
                    - strong [ref=e566]: Skills
                    - text: — progressive-disclosure capabilities you can author yourself; bundled ones are user-owned and only upgraded when you haven't modified them.
                  - listitem [ref=e567]:
                    - strong [ref=e568]: Memory
                    - text: — durable, per-project facts kept across sessions, written automatically after each turn and consolidated in the background.
                  - listitem [ref=e569]:
                    - strong [ref=e570]: Subagents & MCP
                    - text: — in-process subagents with strict tool inheritance, and Model Context Protocol servers configured lazily per project.
                  - listitem [ref=e571]:
                    - strong [ref=e572]: Handoff between machines
                    - text: "— carry a session from one machine to another with a single command: moh publishes a structured synthesis plus a filtered event-log extract as a secret GitHub gist, and offers it at the next startup on the other machine (manual file export/import when"
                    - code [ref=e573]: gh
                    - text: isn't available).
                  - listitem [ref=e574]:
                    - strong [ref=e575]: Always up to date
                    - text: — moh quietly checks for new releases and skill updates while you work (never installing anything without your explicit consent; fully disableable).
                  - listitem [ref=e576]:
                    - strong [ref=e577]: Local usage telemetry
                    - text: —
                    - code [ref=e578]: moh usage
                    - text: reports per-model calls, tokens, estimated costs, tool statistics, and route health from your own session logs, with redacted CSV/JSONL export. Measured locally, never phoned home.
